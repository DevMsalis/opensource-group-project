# Student Result Management System

A web-based **Student Result Management System** developed by **Group J** as part of the **Open Source Software Development** course at **Al-Qalam University Katsina**.

---

## 📖 Overview

The Student Result Management System is designed to simplify the management of students' academic records. It enables lecturers or administrators to record student information, manage course scores, calculate grades and GPA automatically, and display results in an organized and user-friendly interface.

---

## ✨ Features

* Add new students with their matriculation numbers
* Record and manage course scores
* Automatic grade calculation
* Automatic GPA calculation
* Display student results in a structured table
* Search and filter student records
* Print and export result sheets
* Responsive design for desktop and mobile devices

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

## 🚀 Getting Started

### Clone the Repository

```bash

```

### Navigate to the Project Folder

```bash

```

### Run the Project

Simply open the `index.html` file in your preferred web browser.

No installation or additional dependencies are required.
